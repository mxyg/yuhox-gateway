把**藏在 NVR 或第三方视频平台后面的摄像头**接进昱弘边缘预警：网关用账号登录那个平台自动取流，
或者按你填的地址逐条取流，统一转成稳定的 RTSP 批量交给分析盒子。现场那些摄像头一台都不用搬。

需要它的场景：摄像头注册在别人的平台里、盒子直连不到；只对管理账号开放；IP 会漂；
或者一路一路手填 RTSP 填不完。

## 免费，不需要授权

2026-10-24 起，**这个产品免费使用**：不激活、不贴码、不看任何授权结论，装完直接就能取流。
同时能出多少预览，由这台机器当场实测（CPU 与可用内存）决定，机器变强就自动多出几路。
网关转进来的那些路数，计入昱弘边缘预警的摄像头额度，不另收费。

## 先校验，再安装

下载页旁边有 `SHA256SUMS.txt`。算一遍手上的包：

```
Windows（PowerShell）  Get-FileHash -Algorithm SHA256 .\yuhox-gateway-1.20.1-windows-setup.exe
Windows（cmd）         certutil -hashfile yuhox-gateway-1.20.1-windows-setup.exe SHA256
macOS / Linux         shasum -a 256 yuhox-gateway-1.20.1-macos-arm64.dmg
```

对不上就不要装。

要注意的是：这一份清单和安装包放在同一个地方，它能证明包没下坏，**证明不了包没被人换过**。
想真正核对，向我们索取本版本的发布记录（support@yuhox.com，附上文件名），
我们把当时入库的那一份校验值报给你。

## 装完之后

浏览器打开 `http://127.0.0.1:8446/`（这台机器上其它地方访问就用它的局域网地址）。
在页面里选好「平台类型」、填「平台地址」与「平台账号」，它就把那个平台上的摄像头一路一路取成流；
不接平台也可以，用「+ 添加摄像头」逐条填 RTSP 地址。保存后就开始取流。

第一次运行 Windows 可能弹 SmartScreen：点「更多信息」→「仍要运行」。我们没有买代码签名证书，
这一趟是必经的；介意的话请先校验 SHA256 再放行。macOS 上双击打不开时，对着 app **右键 → 打开**一次即可。

防火墙要放行的端口：`8446`（网关网页与取流接口）、`8888`（HLS 预览）、`8889`（WebRTC 低延迟预览）；
要让昱弘边缘预警的管理台自动发现这台网关，还需要 UDP `8442` 能通。
端口不通在管理台上的表现是画面一直转圈，和「摄像头没接好」长得一模一样。

## 它会往外联网吗

不会主动连我们的服务器。它只连你自己在页面上填的那些视频平台与摄像头地址；
不上传画面、不上传账号、不上传日志，现场没有外网也照常工作。
页面上的官网链接是给你点的，不是它自己会去访问的。
